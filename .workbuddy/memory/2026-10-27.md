## 关键技术约束（写进 README 了，务必遵守）
1. KNX climate 必须 `fan_max_step: 3` + `fan_zero_mode: "auto"`，fan_modes 才会等于 mesh 的 auto/low/medium/high。
2. `temperature_step: 1`（mesh 只吃整度）。
3. 空调必须用 `controller_mode_address`（DPT 20.105），否则 6 种模式表达不全。
4. 地暖**不要**配 controller_mode（mesh 侧只有 off/heat）。
5. KNX fan 无 preset：新风 auto 只能按 100% 下发，0% 视为关机。

## 引擎关键实现（别再改回去）
- `normalize_fan_mode()` 按目标实体的 `fan_modes` 归一，表达不了的档位丢弃而不是硬发（硬发会触发服务报错 + 5 次重试）。
- `quantize_percentage()` 用截断，3 档落 33/66/100（四舍五入会出 67，导致每次都要靠容差判等）。
- `resolve_service_calls()` 拆多调用：`climate.set_temperature` 不接受 fan_mode。
- `payloads_equal()` 对 percentage/temperature/brightness 有容差，消除跨协议抖动。
- 启动对齐以**组内第一个实体**为权威；想换权威就调实体顺序。
- 熔断实测参数：2 秒内 ≥8 次 → 熔断 60 秒（README 原来写 60s/10 次/300s，已改）。
