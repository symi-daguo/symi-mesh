# 2026-10-27 — syMI Mesh 1.2.12~1.2.14 审查、三合一现场排障

## 17:30 现场「5 台三合一无法控制」根因（已修）
- **根因：串口独占冲突**。Node-RED 容器的 `symi-gateway` 节点配的是 `serial /dev/ttyS0 @115200`，
  进程一直持有 `fd 22 -> /dev/ttyS0`；HA 的 symi_mesh 也配同一条串口 → 两个 reader 瓜分字节流。
- 症状链：每 5 秒 `Opened serial port` → `Gateway unreachable`（11 分钟 96 次）、
  `Device list timeout; proceeding with 0/1/5 known devices`、三合一识别 0 次、只有 5 个 climate 实体、
  控制下发 29 条但设备无反应。
- 处置：给 Node-RED 的 `symi-gateway` 节点加 `"d": true` 禁用并重启 node-red（配置 `mappings: []`、
  `autoSyncEnabled: false`、`deviceMac: 00:00...`，本来就是空壳连接）。
- 效果：17:24 后重连 0 次；5 台全部识别，15 个实体（每台 climate + fan + floor）一次建齐。
- 遗留清理：Node-RED 曾通过 MQTT discovery 发过 15 个三合一实体（`homeassistant/climate|fan/<mac>_*/config`），
  gateway 停后全部 unavailable。用 `mosquitto_pub -r -n -t <topic>` 清 retained，HA 自动删实体，剩 15 个 symi_mesh。

## HA 2026 长期令牌调服务会 Unauthorized（踩坑记录）
- `/auth/token` 用 long_lived token 或普通 refresh token 换出的 AT：**GET /api/states 200，POST /api/services 401**。
- 用 `.storage/auth` 里 `client_id = http://<ha>:8123/` 的 normal refresh token + 同 client_id 换 AT，
  WebSocket `call_service` 才能成功。验证服务调用必须走这条。
- 现场用户 `symi` 属 `system-admin`，与权限无关。

## 地暖温度调节失效（v1.2.14 已修）
- `0x94` byte6 写死 `18..32`，设备上报 16（机型下限）或 0（未设定）全被丢弃 → `floorHeatingTemp` 为空
  → `target_temperature` 返回 None → 前端滑条不可拖、服务调用不触发。
- 放宽 `5..40`，并给 `target_temperature` 加兜底（地暖 22 / 空调 24），`async_set_temperature` 记录上次值。
- 另修 `0x16 SENSOR_TEMP`：面板未接探头时上报 `0x0000` 被直接采纳成 0.0 ℃，按无效值丢弃（0 或超出 -10..60）。
- 实测：地暖设定 None → 22/25，拖 23 后串口下发 `attr=0x6C param=17`，回读 23.0。

## 关键技术约束（写进 README 了，务必遵守）
1. KNX climate 必须 `fan_max_step: 3` + `fan_zero_mode: "auto"`，fan_modes 才会等于 mesh 的 auto/low/medium/high。
2. `temperature_step: 1`（mesh 只吃整度）。
3. 空调必须用 `controller_mode_address`（DPT 20.105），否则 6 种模式表达不全。
4. 地暖**不要**配 controller_mode（mesh 侧只有 off/heat）。
5. KNX fan 无 preset：新风 auto 只能按 100% 下发，0% 视为关机。

## 引擎关键实现（别再改回去）
- `normalize_fan_mode()` 按目标实体的 `fan_modes` 归一，表达不了的档位丢弃而不是硬发（硬发会触发服务报错 + 5 次重试）。
- `quantize_percentage()` 用截断，3 档落 33/66/100（四舍五入会出 67，导致每次都要靠容差判等）。
- `resolve_service_calls()` 拆多调用：`climate.set_temperature` 不接受 fan_mode。
- `payloads_equal()` 对 percentage/temperature/brightness 有容差，消除跨协议抖动。
- 启动对齐以**组内第一个实体**为权威；想换权威就调实体顺序。
- 熔断实测参数：2 秒内 ≥8 次 → 熔断 60 秒（README 原来写 60s/10 次/300s，已改）。
